# Product Roadmap

This is sequencing guidance, not an instruction to implement beyond the user's requested slice.

1. Tracking core: state, lap capture, summaries, and traces.
2. Local sessions and setup-revision persistence.
3. Stable machine-readable CLI operations for telemetry, sessions, laps, comparisons, and setups.
4. Interactive terminal workspace and multi-terminal attachment to one telemetry owner.
5. Skills for session review, lap comparison, and guided setup proposals.
6. Native AI and MCP adapters over the same application handlers.
7. A separate hosted server for authenticated synchronization and remote access.
8. Web frontend and broader product polish.

See [the product specification](../specs/product.md) for durable intent and [the architecture specification](../specs/architecture.md) for runtime boundaries. The older comprehensive design remains available in [the detailed plan archive](../plan.md) and should be loaded only when a task needs that detail.
