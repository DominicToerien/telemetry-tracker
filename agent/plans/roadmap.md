# Product Roadmap

This is sequencing guidance, not an instruction to implement beyond the user's requested slice.

Completed foundations include tracking, local session/lap persistence, JSON CLI queries, terminal navigation, initial skills, and lossless setup-baseline import.

1. Validate safe, car-specific setup modifications and lossless output round trips.
2. Expand supported cars and settings using representative LMU fixtures.
3. Complete interactive terminal workflows and multi-terminal attachment to one telemetry owner.
4. Add session-review and lap-comparison skills over the stable CLI contract.
5. Add native AI and MCP adapters over the same application handlers.
6. Add a separate hosted server for authenticated synchronization and remote access.
7. Add the web frontend and broader product polish.

See [the product specification](../specs/product.md) for durable intent and [the architecture specification](../specs/architecture.md) for runtime boundaries. The older comprehensive design remains available in [the detailed plan archive](../plan.md) and should be loaded only when a task needs that detail.
