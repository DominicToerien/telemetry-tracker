# BMW M4 LMGT3 fixtures

These unmodified LMU `.svm` examples were selected from
[`seralaci/Le-Mans-Ultimate-Setups`](https://github.com/seralaci/Le-Mans-Ultimate-Setups)
at commit `c7ae1038d075274573fb1e19b3daea1d9e8d50c2`:

- `Monza/BMW M4 Mid DF 5.2.svm` -> `monza-mid-df.svm`
- `Monza/SRA BMW M4 High DF LVL 4.5.svm` -> `monza-high-df.svm`

Both declare the exact car identifier `BMW_M4_LMGT3 GT3 WEC2025`. They provide
real low/high encoded pairs for the initially supported settings and exercise
lossless handling of both ASCII and legacy single-byte setup content.
